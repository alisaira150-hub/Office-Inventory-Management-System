OFFICE INVENTORY MANAGEMENT SYSTEM
Dashboard edition

Technology:
- Python 3 standard library
- SQLite
- HTML and CSS dashboard
- Python built-in HTTP server

Run:
1. Extract the ZIP.
2. Double-click run_dashboard.bat OR open terminal and run: python app.py
3. Open http://localhost:8000

Main features:
- Dashboard summary
- Add item
- Stock inward
- Stock issue
- Inventory search
- Recent transactions
- Low-stock identification
- SQLite data persistence

Important:
Starter data is illustrative sample data for an academic demonstration.
The app is local and is not connected to the training organisation's live system.
The dashboard screenshots in the report are rendered from the same dashboard page generated by app.py.
