# Office Inventory Management System — Dashboard Edition

## Run
1. Install Python 3.9 or newer.
2. Extract this folder and open a terminal inside it.
3. Run `python app.py`.
4. Open `http://localhost:8000` in your browser.

No third-party packages are required. The app creates `office_inventory.db` automatically.

Features: dashboard summary, item master, stock inward, stock issue, stock search, recent transactions, low-stock identification, SQLite persistence, duplicate item-code validation and prevention of excess stock issue.

Starter records are illustrative sample data. This is a local academic demonstration and is not connected to an organisation's live inventory.
